# 探究データラボ

実験で得た測定値をグラフにし、**軸を変換して直線になる関係を探し、傾きから物理量を求める**までを一続きで行う、高校物理のデータ処理アプリです。
インストール・ログイン不要で、スマートフォン・Chromebook・PCのブラウザで動きます。入力したデータは端末の中だけで処理し、外部には送りません。

- 公開URL: https://shin-phys.github.io/inquiry_data_lab/
- 仕様書: [docs/spec/README.md](docs/spec/README.md)

## 3つの入口

| 入口 | 内容 |
| --- | --- |
| 直線化ラボ | 2つの量の関係を調べる。表に測定値を入れ、軸を変換し、手で直線を引いて、最小二乗法と比べる |
| ばらつきラボ | 同じ量をくり返し測った値を整理し、結果を「平均 ± 標準誤差」で書く。2つの群の比較もできる |
| ミステリーデータ | 関係（y = k xⁿ）が伏せられたデータの n と k を、直線化で当てる（5問） |

## 設計の考え方

- **中身が見える道具**：変換後の数値は表に表示し、傾きの計算過程（Σx、Σxy など）も開いて見られます。Excel の SLOPE・INTERCEPT・LINEST と同じ結果になります。
- **答えを先に出さない**：「最適な変換」は提案しません。最小二乗の直線は、自分の手で直線を引いて動かした後にだけ表示できます。軸の変換を変えると、直線は引き直しになります。
- **決定係数だけで判断させない**：隣り合う変換（例：y∝x と y∝√x）は、誤った方でも決定係数が 0.98 近くになります。直線かどうかは、残差の並び方と、原点を通るかどうかで判断します。決定係数は設定でオンにしたときだけ表示します。

## 直線化ラボの使い方

1. **表に入力**：量の名前・記号・単位を入れ、測定値を入力する。Excel やスプレッドシートのセルをコピーして貼り付けられる。CSV（phyphox の書き出しを含む）も読み込める。
2. **軸を変換**：横軸・縦軸それぞれ「そのまま・2乗・3乗・平方根・逆数・逆数の2乗」から選ぶ（設定で常用対数を追加）。軸ラベルと単位も自動で変わる。
3. **直線を引く**：両端のつまみを動かして点に合わせる。傾きと切片が単位つきで表示される。「原点を通す」「傾き三角形」も使える。
4. **確かめる**：「残差を見る」でずれの並び方を確認し、「最小二乗と比べる」で最小二乗法の傾き・切片（± 標準誤差）と比べる。
5. **まとめる**：結論の文をつくり、「傾きから求める」に式（例：`4*pi^2/a`）を入れて物理量を計算する。
6. **保存・共有**：グラフを画像（PNG）、表をCSVで保存。共有URL・QRコードで同じ状態を別の端末で開ける。印刷にも対応。

表の中では、`Enter`・`↓`・`↑` で上下のセルに移動できます。同じ条件でくり返し測ったときは、測定の列を増やすと平均をグラフに使い、標準誤差を誤差棒で表示します。

## URLパラメータ

| パラメータ | 意味 | 例 |
| --- | --- | --- |
| `lab` | 開く入口。`line`（直線化ラボ）、`spread`（ばらつきラボ）、`mystery`（ミステリーデータ） | `?lab=spread` |
| `sample` | 練習用データを読み込んで直線化ラボを開く | `?sample=pendulum` |
| `seed` | 練習用データ・ミステリーデータの乱数の種（数字）。変えると別のデータになる | `?sample=pendulum&seed=3` |
| `big` | `1` で投影モード（文字を大きく） | `?sample=freefall&big=1` |

共有URLでは、データを `#` 以降に圧縮して入れています（サーバーには送られません）。

## 練習用データ

| `sample` | 実験 | 直線になる組 | 傾きの意味 |
| --- | --- | --- | --- |
| `spring` | ばねののび | x と m | g/k |
| `pendulum` | 単振り子 | T² と L | 4π²/g |
| `freefall` | 自由落下 | y と t² | g/2 |
| `boyle` | ボイルの法則 | p と 1/V | pV |
| `light` | 光源からの距離と明るさ | E と 1/r² | 光度 |
| `string` | 弦の振動 | f と √S | 1/(2L√ρ) |
| `ohm` | 抵抗の電流と電圧 | I と V | 1/R |
| `discharge` | コンデンサーの放電（発展） | log V と t | −1/(2.30RC) |
| `kepler` | 惑星の軌道（発展・実データ） | T² と a³ | 1 |

`kepler` 以外は、関係式から計算した値に測定誤差を模した乱数（標準偏差は値の1.5%）を加えたものです。
`kepler` の数値は NASA Planetary Fact Sheet（Ratio to Earth Values）の値です。

## 計算の仕様

- 最小二乗法（y = ax + b）と原点を通る直線（y = ax）。傾き・切片の標準誤差つき。
- 表示の丸め：不確かさは有効数字1桁（先頭の数字が1のときは2桁）、値はその位にそろえる。
- 変換できない値（負の数の平方根、0 の逆数、0 以下の対数）を含む行はグラフから外し、外した行数を表示する。
- 計算式と基準値は [docs/spec/README.md](docs/spec/README.md) と `src/core/core.test.ts` にあります。

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm test         # 自動テスト
npm run build    # 本番ビルド（dist/）
```

main ブランチへのプッシュで、GitHub Actions がテスト・ビルドを行い GitHub Pages に公開します。
初回のみ、リポジトリの Settings → Pages → Build and deployment → Source を「GitHub Actions」にしてください。

| 場所 | 内容 |
| --- | --- |
| `src/core/stats.ts` | 最小二乗法、平均・標準偏差、丸め、目盛り、ヒストグラム |
| `src/core/transform.ts` | 軸の変換と、記号・単位の表示 |
| `src/core/parse.ts` | 入力の整形（全角→半角）、貼り付け・CSVの読み取り |
| `src/core/model.ts` | 表のデータからグラフの点・直線を計算する |
| `src/core/share.ts` | 共有URLの作成と復元 |
| `src/core/mystery.ts` | ミステリーデータの生成と判定 |
| `src/core/calc.ts` | 「傾きから求める」の電卓 |
| `src/data/samples.ts` | 練習用データ |
| `src/ui/` | 画面 |
