# クラス集計（先生用の手引き）

班ごとの測定値を1か所に集めて、クラス全体のグラフにまとめる機能です。
集める先は、先生自身の Google スプレッドシートです（Google Apps Script＝GAS を使います）。
この機能は、先生が配ったリンクから開いたときだけ現れます。ふだんの利用では、アプリは外部と通信しません。

## できること

| 種類 | 使う場面 | クラスの結果画面に出るもの |
| --- | --- | --- |
| ばらつきラボ | 同じ量をくり返し測る（例：同じ振り子の周期） | クラス全体の「平均 ± 標準誤差」、班ごとの「平均 ± 標準誤差」の比較、全員の値のヒストグラム |
| 直線化ラボ | 条件を変えて測る（例：糸の長さと周期） | 全班の点を重ねたグラフ（軸の変換・直線引きができる）、班ごとの傾き ± 標準誤差の比較 |

## 準備（最初の1回だけ）

1. Google スプレッドシートを新しく作る。
2. メニューの「拡張機能」→「Apps Script」を開く。
3. 最初から入っているコードを消し、[`gas/Code.gs`](../gas/Code.gs) の中身を貼り付けて保存する。
   （アプリの「先生用：クラスで集める」画面の「GAS のコードをコピー」でも同じものをコピーできます）
4. 右上の「デプロイ」→「新しいデプロイ」→ 種類で「ウェブアプリ」をえらび、次のように設定してデプロイする。
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
   - 初回は、スプレッドシートへのアクセスを承認する画面が出ます。
5. 表示された「ウェブアプリ」のURL（`https://script.google.com/macros/s/…/exec`）を控える。

コードを更新したときは、「デプロイを管理」→ 鉛筆のアイコン → バージョン「新バージョン」でデプロイし直します（URLは変わりません）。

## 授業での流れ

1. アプリのトップ画面のいちばん下「先生用：クラスで集める」を開く。
2. GAS のURLを貼り、「接続を確かめる」で「つながりました。」と出ることを確かめる。
3. 集める内容（ばらつきラボ／直線化ラボ、タイトル、量の名前と単位）を入れる。
4. 「QRコードを大きく映す」でスクリーンに映し、生徒に読み取ってもらう（リンクをコピーして配ってもよい）。
5. 生徒はふだんどおりラボに入力し、「班の番号」をえらんで「クラスに送る」を押す。送り直すと、前のデータと入れかわる。
6. 「クラスの結果を開く」で結果画面を映す。「更新」または「15秒ごとに自動で更新」で新しいデータが入る。

クラスや授業が変わるたびに「新しい部屋にする」を押してください。部屋ごとにデータが分かれるので、前のデータと混ざりません。
GAS の準備は1回だけで、同じURLを何度でも使えます。

## 送られるもの・残るもの

- 送られるのは **部屋の名前・種類・班の番号（1〜60）・数値** だけです。氏名、メールアドレス、端末の情報は送りません。
  GAS 側でも、数値以外の項目は捨ててから記録します。
- データは、スプレッドシートの「class_data」シートに1行ずつ追記されます（時刻・部屋・種類・番号・データ）。
  送り直しも別の行として残り、集計では番号ごとに最後の行だけを使います。
- 消したいときは、スプレッドシートの行を消してください。
- 結果画面の「使う」のチェックを外すと、その班はその画面の集計からだけ外れます（データは消えません）。

## 注意

- GAS のURLを知っている人は、誰でも数値を送れます（数値以外は受け付けません）。リンクは授業の中だけで配ってください。
- 学校の Google アカウントでは、「アクセスできるユーザー：全員」をえらべない設定になっていることがあります。
  その場合、この機能は使えません（ログインが必要な設定には対応していません）。個人のアカウントで作るか、管理者に確認してください。
- クラス全員が同時に送ると、GAS が混み合って失敗することがあります。アプリは少し待って2回まで自動でやり直しますが、
  それでも「つながりませんでした」と出たら、もう一度「クラスに送る」を押してもらってください。
- 1回に送れるのは、ばらつきラボで100個まで、直線化ラボで50点までです。

## 通信の取り決め（開発者向け）

| 操作 | 送るもの | 返るもの |
| --- | --- | --- |
| 接続の確認 | `GET …/exec?ping=1` | `{"ok":true,"app":"inquiry_data_lab","v":1}` |
| 送信 | `POST …/exec`、本文は文字列の JSON：`{"room":"K4P2QX","kind":"spread","g":3,"d":{"v":[1.42,1.38]}}`（直線化は `"kind":"line"`, `"d":{"r":[[x,y],…]}`） | `{"ok":true,"t":時刻}` |
| 読み出し | `GET …/exec?room=K4P2QX&kind=spread` | `{"ok":true,"items":[{"g":3,"t":時刻,"d":{…}},…]}`（番号ごとに最後に届いたもの） |

- 失敗のときは `{"ok":false,"error":"bad_request"}` または `"server_error"`。
- 送信は `Content-Type: text/plain` で送ります（事前確認のリクエストが飛ばず、GAS がそのまま受け取れるため）。
- GAS を用意せずに試すには、`node gas/mock-server.mjs` で模擬サーバーを立て、`npm run dev` で開いたアプリのURL欄に
  `http://localhost:8787/exec` を入れます（localhost のURLは、アプリ自体を localhost で開いているときだけ受け付けます）。
- `Code.gs` は、`src/core/classroom.test.ts` で模擬環境に読みこんで検算しています。
