## 第1版の実装メモ

仕様書どおりに実装しています。仕様書から変えた点・補った点は次のとおりです。

| 項目 | 内容 |
| --- | --- |
| 基準値の訂正 | 原点を通る直線の傾きの標準誤差は 0.0222866（仕様書の当初の記載 0.0222870 は転記の誤り）。計算式は仕様書どおり |
| 軸を変えたときの直線 | 軸の変換を変えると、手で引いた直線と最小二乗の表示を消し、引き直しにする（変換ごとに自分の目で直線を合わせさせるため） |
| 変換後の列 | 表に追加する変換後の列は、変換した軸の分だけにする |
| `kepler` の数値 | NASA Planetary Fact Sheet（Ratio to Earth Values）の有効数字3桁の値を使い、出典をヒント欄に表示する |
| 共有URL | lz-string で圧縮して `#d=…`（直線化ラボ）、`#s=…`（ばらつきラボ）に入れる |
| CSV の行数 | 50行を超えるCSVは、等間隔に50行へ間引いて読み込む（phyphox の長い記録を想定） |
| ヒストグラムの階級幅 | スライダーではなく「細かく」「粗く」のボタンで、1・2・5 の刻みを1段ずつ動かす |
| ばらつきラボの除外 | 30個以下は点をタップ、それより多いときは値の一覧をタップして除外する |
| スマートフォンでの描画 | 幅 640px 未満では小さい枠（380×330）に描き、目盛りの文字が小さくなりすぎないようにする |
| 表のキー操作 | Enter・↓・↑ で上下のセルに移動する |
| ミステリーデータ | 2回まちがえると残差を見るよう促し、「答えを見る」も選べる。自力で当てた数を得点にする |

## 第1版で作っていないもの

- 誤差棒を重みに使う最小二乗法、曲線を直接あてはめる機能
- 複数のデータ系列を1つのグラフに重ねる機能
- センサーやトラッカーからの直接取り込み（CSVと貼り付けで代用）
- サーバーへの保存、クラス全員のデータの自動集約

## 表示と印刷

- 画面幅 640px 未満ではグラフを縦長の小さい座標系（380×330）で描き直す。拡大縮小ではなく描き直すので、スマートフォンでも目盛りの文字が読める大きさになる。
- 画面幅 1024px 未満の直線化ラボは「表／グラフ／まとめ」のタブ切り替え。
- 印刷（A4縦）は左に表、右にグラフ・読み取り・残差・結論を並べて1枚に収める。操作用のボタン、ヒント、空の行、未入力の「傾きから求める」は印刷しない。Yの列が多い表（4列以上）は左の幅に収まらず文字が詰まることがある。

## クラス集計（初版のあとに追加）

仕様書の初版にはなかった機能。先生の Google Apps Script（GAS）にデータを集め、クラス全体でまとめる。手引きは [../class-mode.md](../class-mode.md)。

- **任意の機能**：先生が配ったリンク（`#k=…`）から開いたときだけ、ラボに「クラスに送る」が現れる。それ以外では通信しない。
- **送るもの**：部屋の名前・種類・班の番号（1〜60）・数値だけ。氏名などの入力欄は作らない。GAS 側でも数値以外を捨ててから記録する。
- **送り先の制限**：リンクに入れられる送り先は `https://script.google.com/…/exec` だけ。それ以外のURLが入ったリンクは読まない。
- **部屋**：授業ごとに名前を変えてデータを分ける。同じ番号から送り直すと、あとから届いたものを使う（記録は両方残る）。
- **作業の保存**：クラス集計に参加しているあいだの入力は、部屋ごとの別の場所に保存する（ふだんの作業と混ざらない）。
- **結果画面（ばらつき）**：クラス全体の平均 ± 標準誤差、班ごとの平均 ± 標準誤差、全員の値のヒストグラム。班ごとに集計から外せる。
- **結果画面（直線化）**：全班の点を1つの表にまとめて直線化ラボと同じ作業台で扱う。班ごとの傾きは、作業台と同じ軸の変換・「原点を通す」の設定で最小二乗法をあてはめる。
  班ごとの傾きは、手で直線を引く前でも表示する（各班はすでに自分のラボで手引きを済ませている想定）。
- **混雑への対応**：送信に失敗したら、少し待って2回まで自動でやり直す。結果画面の自動更新は15秒ごと・初期設定はオフ（全員が開いても GAS が混み合わないように）。
- **対応しないもの**：ログインが必要な GAS（アクセスできるユーザーが「全員」でないもの）。
